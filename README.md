# Предварительное КП · Solaris — заявки из Telegram в 1С, маршруты, подтверждение доставки (Cloud Plus)

Одна страница `index.html` без сборки. Источник — предварительное ТЗ по итогам встречи (`src/tz.docx`, текст в `src/tz.txt`).

- Живая страница: https://abmarat11-art.github.io/demo-kp-solaris/
- Поля для заполнения — элементы с `data-field`: date, meeting-date, t1–t4 (сроки), p1–p4 (стоимость), pay1–pay4 (оплата), valid-until, person, phone.
- Стиль: письмо-предложение в одну колонку, без иконок и картинок; две анимации по смыслу (цепочка участников, один день доставки) + появление блоков при прокрутке.
